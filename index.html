Methodology

Data Preprocessing: Cleaned raw Hyperliquid execution data by parsing intraday timestamps, casting PnL/Volume to numeric types, and removing corrupted records.

Merging by Date: Mapped the daily Bitcoin Fear & Greed index values to the exact intraday trade execution timestamps to create a unified time-series dataset.

Null Handling: Filtered out unclassified trades and forward-filled missing sentiment indices where applicable to ensure robust aggregations.

Feature Engineering: Created aggregated features such as "Win Rate", "Total PnL per Regime", and utilized bucketing logic to categorize extreme market states dynamically for quantitative modeling.
